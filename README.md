# StudyPit 📚🎥

StudyPit is a student-powered web app designed to collect, organize, and share helpful study-related YouTube videos. Whether you're pulling an all-nighter before finals or trying to wrap your head around a tough concept, StudyPit helps you find the right video resources filtered by your academic year, semester, and subject.

## ✨ Features

- **Structured Navigation:** Browse videos organized cleanly by academic years (1st through 4th year) and semesters.
- **Subject-Wise Filtering:** Easily find content tailored to specific engineering and college subjects (like CSE and ECE courses).
- **Community Driven:** Students can easily contribute by adding their own favorite YouTube learning links via a quick submission form.
- **In-App Player:** Watch embedded videos seamlessly without having to leave the site.
- **Dynamic Accents:** Features randomized color accents to keep the UI fresh every time you visit.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Database:** Firebase Firestore
- **Icons & Fonts:** FontAwesome & Google Fonts

## 🚀 Getting Started

If you want to run this locally or host your own version for your college/batch:

1. Clone or download this repository.
2. Set up a project on **Firebase Firestore**.
3. Plug your own Firebase credentials into the `firebaseConfig` object inside `index.html` and `study.html`.
4. Open `index.html` in your browser or deploy it via GitHub Pages, Vercel, or Netlify.
